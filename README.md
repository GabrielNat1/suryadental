# SuryaDental
A web application developed to support the Customer Success team in managing, searching, and analyzing tickets and customer information.

The project was created based on a requirements analysis aimed at identifying challenges in the customer service and ticket analysis processes. Currently, part of these activities relies on spreadsheet exports, manual data consolidation, and searching for information directly within individual tickets.

The system is designed to centralize this information in a single platform, allowing ticket data to be organized, searched, filtered, and analyzed more efficiently. This helps reduce manual work and makes it easier to obtain information for monitoring customer service activities and supporting decision-making.

The main challenges considered during development include analyzing large volumes of tickets, having to access tickets individually to find specific information, and the lack of a consolidated view of the available data.

The system is designed to provide a more organized structure for ticket management, customer lookup, data import, and key metric visualization, while serving as a foundation for future automation and integration with other systems
> The repository does not contain any real data, credentials, or confidential information
